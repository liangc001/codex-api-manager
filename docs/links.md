# 常用链接

首页的“快捷访问”可以直接打开常用网站。“全部链接”按 AI 网页、社区、文档学习、开发工具、日常工具、科研检索和服务状态分组，提供 55 个推荐入口。

点击网站旁的星标可固定到首页，最多显示 8 个；再次点击可取消。支持搜索、添加自定义链接，在“管理”中编辑或移除，误删后可点“撤销移除”。链接在默认浏览器打开，网络路径遵循浏览器本身的代理设置；客户端代理模式不会自动为外部浏览器开启代理。

偏好在第一次修改后写入 EXE 旁 `data/links.json`；该文件跟随完整 data 目录迁移，升级不会重置。首次读取推荐库不写文件、不访问外部网站，也不下载第三方图标。只允许 HTTPS 网页地址，不接受包含账号密码的地址或本地程序协议。个人链接文件不属于 API 配置导出或公开源码；网站的登录、付费与地区限制由各站点决定。
