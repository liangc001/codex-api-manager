# 启动登录

Windows 正式版首次打开需要输入维护者提供的启动密码。成功后自动记住此电脑；下次打开或更新后会直接进入主页。启动密码与隐藏主题的口令独立。

需要重新验证时，在 **设置 → 外观与更新 → 自动登录** 中点击 **清除登录**。它只清除这台电脑的登录状态，不删除 API 或 VPN 配置，也不影响当前正在使用的连接。

程序只保存加盐 scrypt 校验值，密码不会写进配置、日志或发布说明。自动登录凭据由 Electron safeStorage 调用 Windows 当前用户加密，保存在 EXE 旁的 `data/cache/startup-access.bin`。换电脑或 Windows 用户后无法解密，需要重新输入；维护者更换密码校验值后，旧登录状态也失效。解锁前不初始化 API 管理、请求监控、自动修复或 VPN。

启动登录用于限制普通使用，不是 API 服务端鉴权，也不是配置文件的加密密码。公开源码或客户端可被修改，所以不要依赖它保护随软件共享的密钥或节点。正式发布的 EXE 不含这些数据，使用者需提供自己的配置。

从源码直接开发运行时默认不显示登录窗；使用 `API_SWITCHBOARD_REQUIRE_ACCESS=1` 可验证完整登录流程。打包正式版始终启用，环境变量不能关闭。密码更新需要发布新的 `desktop/access-config.cjs` 校验值，不能把明文密码提交到仓库。
