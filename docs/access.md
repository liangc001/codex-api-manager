# 启动登录

Windows 正式版首次打开需要输入维护者提供的启动密码。成功后自动记住此电脑；下次打开或更新后会直接进入主页。启动密码与隐藏主题的口令独立。

从 1.0.54 起，维护者授权的 VPN 运行资料以 AES-256-GCM 加密资源随 EXE 分发，使用启动密码经独立的 scrypt 盐派生解密密钥。新电脑输入一次启动密码后自动配置 VPN，不需要再选择便携目录。已记住登录的旧版用户如果从未配置 VPN，会补验一次密码；已有完整 VPN 目录不会被替换。API Key 不包含在此资源中。

需要重新验证时，在 **设置 → 外观与更新 → 自动登录** 中点击 **清除登录**。它只清除这台电脑的登录状态，不删除 API 或 VPN 配置，也不影响当前正在使用的连接。

程序只保存加盐 scrypt 校验值，密码不会写进配置、日志或发布说明。自动登录凭据和 VPN 资源解密密钥由 Electron safeStorage 调用 Windows 当前用户加密，保存在 EXE 旁的 `data/cache/startup-access.bin`。换电脑或 Windows 用户后无法解密，需要重新输入；维护者更换密码校验值后，旧登录状态也失效。解锁前不初始化 API 管理、请求监控、自动修复或 VPN。

启动登录用于限制普通使用，不是 API 服务端鉴权。加密资源中的 VPN 凭据在知道密码的人之间共享，成功配置后存在本地 `data/vpn`。密码可被转发，也可能受到离线猜测；公开客户端的界面限制可被修改。维护者已选择使用现有启动密码分发这些 VPN 资料。API Key 仍由使用者自己配置。

从源码直接开发运行时默认不显示登录窗；使用 `API_SWITCHBOARD_REQUIRE_ACCESS=1` 可验证完整登录流程。打包正式版始终启用，环境变量不能关闭。密码更新需要发布新的 `desktop/access-config.cjs` 校验值，不能把明文密码提交到仓库。
