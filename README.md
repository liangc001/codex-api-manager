# Codex API 管理

[下载 Windows 便携版](https://github.com/liangc001/codex-api-manager/releases/latest) · [所有版本](https://github.com/liangc001/codex-api-manager/releases)

下载 EXE，放到有写入权限的文件夹后双击。首次启动进入操作教程，自行添加 API。软件不附带任何服务商 Key 或个人配置。

Windows 10/11 x64 便携桌面工具。双击 `Codex-API-Manager-1.0.20-Windows-x64.exe`，无需安装 Node.js 或打开浏览器。软件配置、日志、备份和缓存全部保存在 EXE 旁的 `data` 文件夹。首次启动 API 列表为空，不预置服务商，不自动导入本机密钥。

## 便携使用

首次打开空配置时自动进入操作教程：添加自己的 API → 实际切换 → 确认重启 Codex。教程固定在右下角，滚动仍可见，只显示当前步骤的简短提示和进度；卡片操作按钮与实际操作联动，并高亮对应的界面按钮。保存成功、切换成功、重启成功后才推进；取消或失败停留原步骤。添加表单内显示固定提示，可随时退出教程，保留已保存的 API。关闭后不再自动进入，顶部问号可重新开始。使用提示默认折叠；已打开教程的标记保存在 EXE 旁 `data/cache` 的界面存储中。教程不自动发送测试请求，完成后用户自行发送“你好”；CLI 仍需手动重新打开。

```text
我的工具/
  Codex-API-Manager-1.0.20-Windows-x64.exe
  data/
    settings.json
    profiles.json
    secrets.key
    backups/
    logs/
    cache/
```

- 搬到自己的另一台电脑：正常关闭软件（关闭监控会恢复直连，等待已有请求完成），复制整个文件夹，包含 EXE 和完整 `data`。原有 API、Key、模型、用量快照和日志设置都会保留。新电脑需要安装 Codex，选中 API 点击“切换”，再重新打开桌面 App / CLI。
- 给其他人一个空软件：只复制 EXE 到一个没有 `data` 的新文件夹。对方首次启动会自动建立空配置，自行添加 API。不要把个人的 `data` 一起发出去。
- 升级：先关闭旧版，把新版 EXE 放在同一个文件夹，沿用 `data`。同一文件夹放多个版本 EXE 会共享数据。
- 重置为空：正常关闭软件，把 EXE 旁的 `data` 文件夹改名备份，再启动。不要删除 `.codex`。删除 `secrets.key` 不会重置软件，而是导致现有密钥无法解密。

EXE 旁的文件夹需有写入权限。不要放在只读目录或 `Program Files`。便携 EXE 的内置组件仍由系统在临时目录解压运行，退出后处理；这些不是持久用户配置。

## 密钥保护

编辑 API 时加载该条目的 Key，默认以密码形式隐藏，点击眼睛可查看。关闭编辑框后清空界面中的 Key。Key 未改动或留空时保留原值；更改 API 地址时需要重新填写 Key。

桌面便携版使用 AES-256-GCM 加密 Key 和配置备份，随机密钥保存为 `data/secrets.key`，不依赖 Windows DPAPI，所以可以跨电脑和账号迁移。`profiles.json` 的名称、URL、模型等元数据仍是明文。

**密钥文件随数据一起保存，拿到完整文件夹的人能解密并使用其中的 API Key。** 这能避免配置 JSON 直接出现明文 Key，但不能防止整个文件夹被复制后的密钥泄露。只复制 `profiles.json`、漏掉 `secrets.key`、用另一份密钥文件替换它，都无法解密已有数据；不会静默覆盖密钥文件。Codex 自身的 `auth.json` 仍按 Codex 所需格式保存当前 Key。

另一台电脑或账号的切换备份不能撤销到本机。监控异常恢复备份来自其他电脑时，仅归档到 `backups`，不覆盖本机 Codex 配置。搬迁前仍应正常退出原电脑上的软件。

## 导入与导出

API 列表按规范化后的 URL 自动分组，每组显示一次地址及 API 数量。组内各 API 的名称、Key、模型、用量、编辑、删除和切换保持独立；分组不修改或合并已有配置文件。导出仍可逐个选择 API。

API 列表右上角提供“导入配置文件”和“导出 API”图标，悬停显示名称。“导入当前 Codex 配置”只读取本机当前连接；地址和 Key 都相同才更新已有 API，同地址但不同 Key 会新增一条，不覆盖原配置。

- 导出：默认全选已填写 Key 的 API，可取消部分 API 或取消全选后逐个勾选。每个导出的 API 都包含 Key；未填写 Key 的项目不能导出。JSON 文件含明文 Key，需要妥善保管。只导出名称、地址、模型、推理档位、用量查询类型和 Key，不包含内部 ID、用量快照、日志、备份、当前连接或本机加密文件。
- 导入：选择本工具导出的 JSON，预览并勾选需要的 API，Key 会一起导入。预览不显示密钥，缺少有效 Key 的文件会被拒绝。相同名称和规范化后相同地址视为重复，同地址但不同名称的账号可分别保存。重复项默认跳过，可选择覆盖（包含 Key）。关闭监控后才能覆盖正在监控的 API。
- 导入后的 Key 使用本机便携密钥重新加密，无需对方的 `secrets.key`。导入不自动切换 Codex 连接，也不更改本机日志设置或备份；批量保存失败时保持原 API 列表。
- 支持本工具的 `format: "codex-api-manager"`、`version: 1` 交换格式，单文件最多 8 MiB、500 个 API。不是任意 Codex TOML 或其他管理器格式的通用导入器。取消预览会清除后台暂存的密钥，预览 15 分钟后过期。

## 存储与日志

| 内容 | 相对于 EXE 的位置 |
| --- | --- |
| 软件设置：日志开关、保留天数 | `data/settings.json` |
| API 列表、加密 Key、最近一次用量结果 | `data/profiles.json` |
| 便携加密密钥 | `data/secrets.key` |
| 加密切换备份及归档恢复文件 | `data/backups/` |
| 当前监控的加密恢复文件 | `data/monitor-session.json`，正常关闭后删除 |
| 运行日志 | `data/logs/events-日期-随机编号.jsonl` |
| Electron/Chromium 缓存和崩溃目录 | `data/cache/` |

设置文件不保存绝对数据路径，启动时始终使用当前 EXE 旁的 `data`，移动文件夹后不需要修改路径。便携版不再选择独立的外部数据目录，改变位置时移动整个软件文件夹即可。右上角齿轮展示实际目录，提供打开文件夹、日志开关、保留时间和清空日志。

运行日志默认开启，保留 30 天，可选 7 / 30 / 90 天。按日或单文件约 10 MiB 轮换，启动、换日、轮换及修改设置时清理过期日志，当前目录总量限制约 100 MiB。关闭日志不会删除已有日志；清空日志需确认，不影响 API 和备份。

每行一条 JSON，可用记事本查看。只记录启动/退出、操作类型、结果、API 内部 ID、经过监控的 HTTP 请求状态和耗时。不记录 Key、URL、提示词、回答、请求体、模型字段或原始错误内容。内部 API ID 对应 `profiles.json` 的 `id`。请求日志需要开启实时监控，日志开关本身不会更改 Codex 连接。

不保存完整余额历史，每个 API 只保留最新查询结果。实时统计和最近请求表在内存中保存，重启清零；已完成请求的安全元数据可写入日志。切换备份不受日志保留天数影响。

**Codex 自己的配置与聊天记录由 Codex 管理，仍在 `%USERPROFILE%\.codex` 或 `CODEX_HOME` 指定的目录。** 本工具不会搬走 Codex 的整个数据目录。切换时写入该电脑的 `config.toml` 和 `auth.json`。

## 切换与用量

顶部圆形箭头图标可重启 Codex 桌面 App，操作前确认，未运行时可直接打开。每次从当前电脑识别 `OpenAI.Codex` Windows 包、本地安装目录、卸载注册表及正在运行的 Codex 桌面程序，不保存原电脑的安装路径。额外安装位置通过程序的 Codex 产品信息校验，避免把普通 ChatGPT 或 CLI 当作桌面 App。先请求正常关闭，仍未退出时仅结束识别出的桌面程序，再重新打开；正在进行的请求可能中断。独立 CLI 终端需要自行重新打开。

点击“切换”会先保存加密备份，再修改 Codex 默认连接，保留其他设置和注释。桌面 App 和 CLI 使用相同配置目录时都会读到设置；已运行的进程需要重新打开。项目配置、启动环境变量、CLI `--profile` / `--config`、远程主机及 WSL 的单独配置可能覆盖默认连接。

切换、同步或更改监控后显示右下角悬浮重启提醒，滚动时仍可见，提供“立即重启”和“稍后”；稍后仅收起当前提醒，重新打开工具后仍提示未生效配置。取消重启时保留提醒，确认重新打开成功后清除。未重启就撤销回原配置时清除提醒；已经重启后再撤销，仍需重启以重新加载原配置。工具保存连接配置的指纹用于判断撤销状态，不保存明文 Key；独立 CLI 需手动重新打开。教程开启期间隐藏独立重启卡片，避免与教程卡片重叠。

每条 API 旁的插头图标为“测试连接”。确认后直接向该 API 的 Responses 接口发送一次“你好”，使用该条目的模型，会产生少量用量，最多等待 45 秒；不修改当前 Codex 配置，也不需要开启监控。只有收到模型完成响应才显示成功，HTTP 200 但流式错误或提前中断不会算成功。显示状态、耗时和针对 Key、权限、模型、限流、额度、接口及网络的排查提示。测试不跟随跳转、不关闭 HTTPS 校验、不展示或保存原始响应和回答。最近测试结果只在当前运行期间保留，编辑条目后清除；日志保留安全的状态和错误类别。

设置中的“导出诊断”保存独立 JSON 文件，包含工具版本、系统平台、配置是否匹配、环境变量覆盖是否存在、监控和日志状态、按序号标识的 API 状态及最近测试结果、最近最多 200 条经过白名单过滤的操作记录。不导出 Key、加密密钥、名称、地址、个人路径、配置原文、提示词、回答或原始错误响应。日志关闭时历史记录可能不完整，当前运行期间的测试结果仍可导出。诊断文件不可保存到 data 或 Codex 配置目录中，避免覆盖运行文件；它不是 API 配置交换文件，不可作为配置导入。

旧对话可能保留创建时的服务商标识（例如 `custom`）。切换时同步本机所有 `requires_openai_auth = true`、`wire_api = "responses"` 且使用全局 Key 的已配置服务商地址，防止旧地址与新 Key 混用；重启后可继续这些旧对话。独立环境变量、Bearer Token 或 Authorization 请求头认证的服务商不参与同步。监控开启、关闭和撤销也恢复对应地址。迁移到另一台电脑时重新读取该电脑的服务商表，无需沿用原电脑的路径；聊天记录仍由 Codex 管理，本工具不迁移对话，也不改写对话文件。内置 OpenAI 服务商及其他协议的旧对话不属于这项兼容范围。

“撤销切换”恢复本机最近一次切换前的完整配置；文件后来被其他程序修改时会停止恢复。切换失败会尝试回滚。

- CodexZH：New API `/api/usage/token`，显示此 Key 的原始剩余额度和已用额度，不假定美元换算；无限额 Key 不代表账户余额无限。
- ResearchLab：Sub2API `/v1/usage`，按响应显示余额、套餐或 Key 额度及今日统计。
- 其他地址：自动尝试上述接口；不支持或查询失败时显示实际状态，不编造余额。
- 用量查询仅发送 GET 请求，不发送付费模型请求；账户余额可能包含其他 Key 的消费。
- 用量接口允许同站点、同路径仅添加末尾斜杠的一次跳转；其他跳转不会携带 Key 跟随，并显示接口跳转不兼容。

## 实时监控

先切换到已保存 Key 的 API，再打开“实时监控”。软件保存恢复快照，把 Codex 地址改为仅监听 `127.0.0.1` 的本机代理并使用随机本地令牌。重新打开 Codex 后，请求才会经过代理；监控期间保持本工具运行。

- 显示本机代理当前并发、峰值、最近一分钟请求数、HTTP 成功/失败、429 次数、平均首字节及最近 30 条请求。不是服务商账户全局并发或剩余可用并发。
- 首字节计至上游响应头，不是模型首个 Token；HTTP 2xx 不保证模型回答成功。
- 支持 HTTP Responses、Responses compact、模型列表及 Chat Completions，当前不支持 WebSocket。TLS 校验保持启用。
- 切换时已有流保持原服务商，新请求切到新服务商。
- 关闭监控恢复直连，关闭软件先恢复并等待当前请求结束。Codex 更新或修改其他设置时，只恢复监控写入的连接字段，保留新增设置、注释及手动修改的 Key；冲突快照归档为 `backups/monitor-conflict-*.json`。连接已被其他程序改走时保留当前连接并停止监控，不会因为配置冲突卡住退出。异常退出后下次启动同样尝试恢复，支持旧版监控快照；遇到文件权限等错误时可选择保留备份并退出。
- 监控开启时 Codex 的 `auth.json` 保存本地代理认证令牌，不是服务商 Key；服务商 Key 仍加密保存在 API 列表，代理转发时使用。使用同一全局 Key 的旧服务商地址也切至本机代理。切换服务商后应重启 Codex，已运行对话的配置需重新加载。

## 开发

需要 Node.js 22 或更新版本：`npm install`、`npm run desktop`、`npm test`、`npm run build:exe`。

桌面源码开发默认使用项目根目录的 `data`，此目录不加入版本控制，不包含在 EXE 中。仍保留 `npm start` / `Start.cmd` 浏览器开发版，它沿用旧的本机存储和 Windows DPAPI；日常使用桌面 EXE。

软件独立实现，使用 Electron、TOML 解析器、Lucide 图标，未复制 CC Switch 源码。EXE 内置运行环境，因此约 96 MiB。
